# Лабораторна робота №2

Проєкт містить інструменти для безпечного управління обліковими записами, аутентифікацією, а також для аналізу лог-файлів та виявлення витоків конфіденційних даних (PII).

---

## Task 1: Модель користувача й облікового запису (User & Account Security Model)

Реалізація об'єктно-орієнтованої моделі безпеки облікових записів, безпечного збереження паролів, сесій та аудиту подій.

### Основний функціонал:
* **Безпека паролів (`User`):** Хешування за допомогою `hashlib.pbkdf2_hmac` ("sha256") з випадковою сіллю (`os.urandom`) та безпечним порівнянням часу через `hmac.compare_digest`.
* **Валідація Email:** Валідація форматів за допомогою регулярних виразів (`re`) через `@property`.
* **Наслідування (`Admin`):** Розширення базового користувача списком прав доступу (`permissions`).
* **Управління сесіями (`Session`):** Облік часу активності в UTC (`timezone.utc`) та таймаут сесій.
* **Журнал аудиту (`AuditLog`):** Фіксація подій безпеки (`login_success`, `login_failure`, `logout`) з використанням `@dataclass`.
* **Композиція (`UserAccount`):** Об'єднання користувача, сесії та логування, підтримання спеціальних методів `__getitem__` / `__setitem__`.

### Як запустити демонстрацію Task 1

Демонстраційний сценарій створює об'єкти, перевіряє аутентифікацію, права адміністратора, зміну email та таймаут сесії.

Відкрийте термінал у кореневій папці проєкту та виконайте команду:

```bash
python -m labs.lab02.main demo 
```


## Task 2: Сканер витоків конфіденційних даних (PII Exfiltration Scanner)
Утиліта для рекурсивного пошуку, маскування та логування незахищених персональних даних (PII) у лог-файлах та текстових документах.

### Основний функціонал:
* **Рекурсивний пошук:** Обхід директорій за допомогою pathlib.Path.

* **Детекція PII (re)**: Пошук e-mail адрес, номерів банківських карток, номерів телефонів та IPv4-адрес.

* **Маскування даних:** Безпечне відображення конфіденційних записів (наприклад, 4111-****-****-1111 або u****r@example.com).

* **Агрегація статистик** : Підрахунок знайдених збігів за допомогою collections.Counter.

* **Звітність:** Генерація підсумкового JSON-звіту та логування попереджень.

Відкрийте термінал у кореневій папці проєкту та виконайте команду:
```bash
python labs/lab02/task2.py --scan-dir labs/lab02/data_v13 --patterns all --mask --out-json labs/lab02/scan_report.json
```
